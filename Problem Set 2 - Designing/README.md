# CS50 SQL Problem Set 2

Welcome to **Problem Set 2** of CS50’s Introduction to Databases with SQL!  
In this set, the focus shifts to **database design**—creating schemas from scratch for real-world scenarios.  
The challenge is not just querying existing data, but designing **tables, keys, and relationships** that reflect the needs of organizations.

---

## Projects Overview

### 1. ATL
**Hartsfield-Jackson International Airport (ATL)**, located in Atlanta, Georgia, has been the **busiest airport in the world since 1998**. In 2022 alone, it served 93.7 million passengers.  

Task:  
Design a database that could keep track of passengers and their flights.

---

### 2. Happy to Connect
**LinkedIn** is the world’s largest professional network, where users list their jobs, education, and connections.  

Task:  
Create a schema for LinkedIn’s core features, enabling users to post professional experience and connect with one another. 

---

### 3. Union Square Donuts
**Union Square Donuts** is a beloved shop in the Boston area, known for its gourmet donuts. They’ve relied on paper receipts but now need a digital system to manage customers and orders.  

Task:  
Design a schema for Union Square Donuts to handle orders, customers, and day-to-day operations.

---

## Technologies
- **SQLite** for database creation  
- SQL schema files (`schema.sql`) for table definitions  
- Concepts: **Entity-Relationship Modeling**, **Normalization**, **Constraints**
