# CS50 SQL Problem Set 1

Welcome to **Problem Set 1** of CS50’s Introduction to Databases with SQL!  
This set of projects builds on the foundations of SQL learned in Problem Set 0 and introduces more complex querying, database analysis, and real-world data challenges.

---

## Projects Overview

### 1. Packages
You are a **mail clerk for the city of Boston**, responsible for overseeing mail delivery across the city. Most packages are delivered successfully—but sometimes, a **mystery package** goes missing.  

Your tasks for each reported missing package:
- Determine the **current address or location** of the package  
- Identify the **type of address or location** (e.g., residential, business)  
- Find out the **contents of the package**  

All of this is done using the **packages.db** database, which tracks package transit across the city. Using only the information in the database, your goal is to help customers locate their missing packages.

---

### 2. DESE
You’ve just started as a **data analyst for the Massachusetts Department of Elementary and Secondary Education (DESE)**, which oversees the state’s public education system. DESE ensures that every child receives a quality education with access to resources and experienced teachers.  

Your role is to leverage your **SQL skills** to answer questions about education across Massachusetts using the **dese.db** database. The database contains data on schools, students, and education outcomes, allowing you to analyze and report on key educational metrics.

---

### 3. Moneyball
The year is **2001**, and you’ve been hired to help the **Oakland Athletics** maximize their limited player budget. The team struggles to hire top players due to financial constraints.  

Using the **moneyball.db** database, which includes information on players, their performance statistics, and salaries, your task is to:
- Identify **high-value players** others might overlook  
- Analyze **performance versus cost** to find hidden gems  
- Help the team make data-driven decisions to outperform expectations
