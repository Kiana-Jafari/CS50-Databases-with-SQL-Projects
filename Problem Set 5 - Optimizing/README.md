# CS50 SQL Problem Set 5

Welcome to **Problem Set 5** of CS50’s *Introduction to Databases with SQL*!  
In this set, you’ll shift your focus from data organization to **query optimization** — learning how **indexes** and **efficient querying** can dramatically improve database performance.

---

## Projects Overview

### 1. In a Snap
After the printing press, postal service, and telegram came the **messaging apps**. Today’s apps — from iMessage to Snapchat — depend on speed measured in **milliseconds**.  

In this project, you’ll write SQL queries for a **photo-messaging app** that allows users to send pictures which expire 30 seconds after being viewed. You’ll focus on performance, writing queries that enable instant communication while ensuring scalability as user numbers grow.

---

### 2. your.harvard
Harvard’s real-world course platform *my.harvard* isn’t known for being fast. Now it’s your turn to change that.  

In this project, you’ll work with a simulated **course registration database**, optimizing it by creating **indexes** that reduce query times for common lookups. You’ll analyze trade-offs between speed and storage, ensuring your database performs efficiently at scale.

---

## Technologies
- **SQLite** for database management  
- **SQL** for query optimization and index creation  
- **CS50 Query Tools** for testing performance and correctness

Please note that the database of the project **your.harvard** is not included, due to its large size. Only the `.sql` file, project structure, and the queries are uploaded, which can be found in `indexes.sql`.
